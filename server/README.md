# DARB - درب

منصة توصيل ذكية في منبج - سوريا.

## التطبيقات
- DARB Customer
- DARB Worker
- DARB Admin
- DARB Central Server

## المميزات
- إنشاء وتتبع الطلبات مباشرة.
- تحديث موقع السائق كل 10 ثوانٍ أثناء التوصيل.
- الدفع عند الاستلام.
- دعم شام كاش بعد الربط الرسمي.
- دعم الليرة السورية والدولار.
- إدارة الأرباح والمصروفات.

## الهوية البصرية
- Dark Green
- White
- Orange

## الهدف
بناء منصة توصيل متكاملة قابلة للتوسع إلى عدة مدن.
